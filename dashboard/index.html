兩來源接合校驗

兩份資料重疊 20 個月（2019-01 到 2020-08）。逐月逐欄比對 ADSL、FTTX、Cable Modem 共 60 筆，結果全數完全相等，差異的中位數與最大值皆為 0.0000%， 低於預先登記的 5% 放棄門檻。
20 期完全一致，較合理的解釋為兩份資料出自同一份上游 NCC 報表。因此本報告一律表述為 同源確認，可安全接合，而不是交叉驗證。
接合規則：以 7164 為主，2019-01 之前用 27953 補；重疊的 20 期一律採 7164。

為什麼不做因果推論

本分析不估計降價的效果， 四種識別策略各自被一項具體事實排除：

01M-Lab 的 ISP 級測速資料已於 2024-03 全球停更，2026 年的事件無資料可用。
02即使有資料，2026-03 事件的後測期僅 4.5 個月，不足以估計穩定效果。
03政府統計僅有技術別而無業者別，無法建立 treatment 與 control 分組。
04改以技術陣營分組後，2022 年的價格戰係由對照組（有線電視業者）發動。

資料斷點的查證過程

2009-04（FTTX 單月 −187,856）與 2020-01（ADSL 單月 −207,430，同月 FTTX +107,873） 各出現一次單月劇變，次月即回歸原趨勢。為確認成因查證三處來源： 兩個資料集的 API 中繼資料未附欄位說明、NCC 官網開放資料頁回應 HTTP 403、 公開搜尋亦無口徑調整的紀錄。三者皆無所獲，因此本看板僅陳述觀察到的事實， 不宣稱成因。 旁證是千分位逗號在整份 7164 中只出現在 2020-01 與 2020-02 兩列， 格式變動與數值劇變同時發生；這仍然只是旁證。

限制

01技術別不等於業者別。FTTX 含台灣大與遠傳，中華電信的貢獻無法分離。同理，若有線電視業者佈建的 FTTH 依技術別歸入 FTTX 欄，本分析會系統性低估 Cable 陣營的實際份額，亦即電信陣營的份額變化可能比觀測到的更大。NCC 的填報規則未經查證，也無法用本資料驗證；此一偏誤的方向對本文結論為保守。
02帳號數不等於用戶數。一戶多帳號、一帳號多人的情況無法辨識。
03不做因果宣稱。事件時點僅供對照，不估計處理效果。
04兩來源接合的殘餘不確定性。0.0000% 代表同源而非互證，兩份共同的系統性偏誤無法用彼此檢出。
05事件時點僅為視覺標記。2022-05 MSO 價格戰（工商時報 2022-05-23）與 2026-03-18 中華電信降價（經濟日報／MoneyDJ）。
06兩處資料斷點成因未證實。若 2020-01 確為統計口徑變更，則 7 年降幅中約 12% 屬定義效果而非市場變化，其餘約 -7.9 個百分點仍為實在的趨勢。
